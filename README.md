# Base Next.js

Proyecto base con Next.js, TypeScript, Tailwind CSS y HeroUI.

## Requisitos

- Node.js 18.18 o superior
- npm

## Desarrollo

```bash
npm ci
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000). La página inicial está en `src/app/page.tsx`.

## Verificaciones y producción

```bash
npm run lint
npm run build
npm run start
```

`npm run start` sirve la compilación de producción creada por `npm run build`.
